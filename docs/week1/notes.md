## 三、五个问题

### 1. 晶格常数和文献值差多少？

a **+1.34%**、b **+2.45%**、c **+3.21%**，体积 **+7.15%**。参考 JCPDS 73-2020（a = 5.457、b = 5.436、c = 16.427 Å；出处 Nat. Commun. 2015, 6, 8340，DOI 10.1038/ncomms9340）。

本次为**定胞弛豫**，晶胞参数完全继承输入 CIF（输入与弛豫后体积均为 262.1 / 522.2 Å³）。因此这 7% 的偏差来自 **ICSD 条目本身**，与 MACE 无关。这也说明该条目与标准卡存在系统性差异，需在 W2 查证是测量条件、固溶成分还是结构标准化所致。

三个轴的偏差乘积 1.0134 × 1.0245 × 1.0321 = 1.0715，与体积偏差吻合，说明数据内部自洽。

### 2. 能量从多少降到多少？说明初始结构偏离平衡多远？

下降 **0.0061 eV/atom ≈ 0.24 kT**（300 K 下 kT = 0.0259 eV）。量级很小，说明 ICSD 实验精修结构本已接近势能面极小，弛豫只是微调。

需注意这个数被**定胞条件压低**：晶胞被固定，残余应力使体系无法弛豫到真正最低点。变胞弛豫后该值应显著增大。

### 3. 两种取胞能量为什么应该一致？差 0.14 meV 说明什么？

理论上，每原子能量在热力学极限下与取胞方式无关，应严格相等。实测 **0.14 meV/atom**（≈ 0.005 kT），量级很小。

但**不能全部归为数值误差**：两个 ICSD 条目的每化学式体积相差 **0.39%**（131.05 vs 130.54 Å³），这是两次独立实验测量/精修之间的**真实结构差异**，不是舍入或有效数字问题（0.073 Å 的差距远超四位数精度）。

因此这次对照混入了第二个变量（结构来源），**不构成干净的等价性验证**。改进方法：从同一常规胞用程序生成原胞，再与常规胞对比。

```python
from pymatgen.core import Structure
from pymatgen.symmetry.analyzer import SpacegroupAnalyzer

s = Structure.from_file("Bi2WO6_ICSD67647.cif")
prim = SpacegroupAnalyzer(s).get_primitive_standard_structure()
prim.to(filename="Bi2WO6_prim_from_conv.cif")
```

预期能量差降至 0.01–0.05 meV/atom。若仍为 0.14 meV，则说明两种取胞在数值实现上不等价，属于严重问题。

### 4. 这一周卡在哪一步？怎么解决的？

**① 装错 Miniconda 版本。** 从清华镜像目录里点了 `py39_4.9.2`，装出 Python 3.9.1 / conda 4.9.2。原因：镜像目录按文件名排序，老版本排在 `latest` 前面。解法：卸载后重装 `Miniconda3-latest`。

**② conda 的 ToS 门禁。** `conda create -y` 报 `CondaToSNonInteractiveError`。原因：2025 年 7 月起 Anaconda 给 conda 加了条款确认插件，而 `-y` 让过程非交互，无法弹窗。解法：先跑三条 `conda tos accept`。

**③ `git add.` 少一个空格。** 报 `'add.' is not a git command`，导致暂存区空、commit 无内容、push 报 `src refspec main does not match any`。解法：`git add .`。

**④ 误判显卡故障。** 自检脚本测出 696 ms 的矩阵乘，看着像显卡有问题。原因：脚本没做 warmup，首次 CUDA 调用要初始化 cuBLAS（十几秒），被平均进 20 次里。解法：预热 10 次后逐次计时，真实值 0.065 ms、40.6 TFLOPS。

### 5. 这个结果能信几分？哪里可能不准？

分三层看：

- **流程正确性**：信任。环境、脚本、文件读写、GPU 计算全部跑通，结果可复现。
- **内部自洽性**：信任。两取胞差 0.14 meV/atom，量级合理，两次弛豫均收敛。
- **外部准确性**：**未知**。尚未与 DFT 对比。当前阶段（环境校验）可接受，但任何定量结论之前必须补上。

具体不确定项：

1. **定胞弛豫**：应力未释放，能量绝对值有系统偏差，量级未量化——W2 变胞弛豫补。
2. **zero-shot 模型**：文献横评五个基础 MLIP 框架，微调后力误差可降 **5–15 倍**、能量误差降 2–4 个数量级（DOI `10.1021/acs.jpclett.5c03801`）。本次为纯零样本。
3. **元素覆盖**：MACE-MP 元素分布不均，Bi 的化合物远少于 Si/Al/Fe。
4. **无长程静电**：截断半径外信息丢失，对离子性氧化物有影响；MACE-Polar 可部分弥补，尚未测试。
