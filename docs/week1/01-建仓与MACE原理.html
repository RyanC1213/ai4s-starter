01建 GitHub 仓库：从零到推上去

先说网络
我这边沙箱访问 github.com 超时，但 api.github.com 通。你的浏览器能打开就行——网页操作走你的网络，git push 走你终端里的网络，两者都不受我这边限制。
如果 git push 也卡住，再考虑 Gitee 兜底（命令完全一样，只换 URL）。

第 1 段：网页上建仓库（3 分钟）

1
打开 github.com，确认已登录
右上角有你的头像 = 已登录。
2
点右上角的 + → New repository
不要点 "Import repository" 或 "New gist"。
3
填三个字段
Repository name：ai4s-starter（全小写，用连字符）
Description：可填 Bi2WO6 relaxation with MACE foundation model
可见性：选 Public
4
下面三个勾全都不选
"Add a README file"、"Add .gitignore"、"Choose a license" —— 一个都别勾。
因为你本地已经有 README 和 .gitignore 了，远程再建一个会冲突，push 时报 failed to push some refs。这是新手第一高频错误。
5
点 Create repository，然后复制页面上的 HTTPS 地址
形如 https://github.com/你的用户名/ai4s-starter.git。
页面会显示一堆命令，先别照抄——它给的初始化和我们本地已有内容重复，按下面第 2 段走。

第 2 段：终端里推送（5 分钟）

在 Anaconda Prompt 里，确认在 project 目录、且提示符是 (ai4s)：

cd C:\Users\Administrator\Desktop\project
git --version          # 没装就去 git-scm.com 下 Git for Windows

git init
git add .
git commit -m "init: Bi2WO6 relaxation with MACE"
git branch -M main
git remote add origin https://github.com/你的用户名/ai4s-starter.git
git push -u origin main
push 时会要密码 —— 填的是 Token，不是登录密码
GitHub 从 2021 年起就不接受账号密码了。你要先生成 Personal Access Token：
网页右上头像 → Settings → 左栏最下 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → 填个名字、Expiration 选 90 天 → 勾选 repo（整个大类）→ 拉到最下 Generate。

⚠️ Token 只显示一次，刷新就看不到了。复制下来存到记事本。
终端提示 Username 填 GitHub 用户名，Password 粘贴 Token（输入时不显示字符，是正常的）。

把这条线串起来看，只有一句话：通用势函数的进步，是从"手工描述符"→"等变网络"→"多体消息"→"大规模预训练"→"微调适配"的一条链。
你现在站在链条的末端：拿一个别人训好的模型，用在你自己的体系上。这既是 2026 年最容易的起点，也是最容易出错的地方——因为模型不会告诉你它错了。

这三条结论，直接影响你怎么用 MACE

  1. 别把 zero-shot 当 DFT 用。JPCL 2026 明确写了：基础模型存在架构相关的系统偏差，微调后力误差才能降 5–15 倍。你的 W1 结果（−6.601 eV/atom）只能说明"流程通了"，不能说明"数值准"。
  2. 你关心的量，恰好对力最敏感。PCCP 2026 指出误差主要来自力误差经 Hessian 放大。而吸附能、反应路径、声子，全都依赖力。做这些量之前，必须先做误差评估。
  3. Bi 是重元素，在训练集里属于少数。MACE-MP 的元素覆盖不均，重元素 + 氧化物缺陷构型的样本更少。这正是你可以做的那篇"适用域研究"的立足点。

03MACE 原理：它到底在算什么

3.1 一句话定义

MACE 是一个从原子坐标直接算出能量的函数。给它一堆原子的种类和位置，它输出一个总能量；力则通过对能量求导得到。

# 概念上它就是一个函数
E = MACE(元素类型[], 坐标[])          # 输出：总能量，单位 eV
F = -dE/dr                            # 输出：每个原子的受力，单位 eV/Å
为什么"力 = 能量对坐标的导数"这件事这么重要
因为这样能量自动守恒。跑分子动力学时，体系不会莫名其妙地升温或降温。
有些模型（如早期的某些 NN 势）直接预测力，训练更简单，但跑长时间 MD 会漂移。MACE 走的是"保守力"路线。

3.2 三块积木

积木一：把"邻居在哪、多远"变成向量（边特征）

对中心原子 i 和邻居 j，有两个信息：距离 r_ij 和方向 r̂_ij。

  • 距离 → 用一组径向基函数展开（类似把"3.2 Å"编码成一串数）
  • 方向 → 用球谐函数 Ylm 展开（就是化学里原子轨道的角向部分，同一套数学）
  • 两者相乘 → 得到"等变特征"，分 l = 0, 1, 2, … 不同阶

「等变」的意思是：你把整个分子旋转一下，这些特征会按规则跟着旋转，而不是乱变。这样网络就不需要靠数据去学"旋转不变性"——它天生就有。

积木二：消息传递（MACE 的核心创新）

普通 GNN 每传一层，信息多走一个键的距离。要让中心原子"感知"到 4 体相互作用（i, j, k, l），得堆 3 层。

MACE 的做法：在同一层内，把邻居两两配对做张量积，直接构造出 3 体、4 体的项。

# 两体消息：只用到 i-j 这一条边
m_ij = RBF(r_ij) ⊗ Y_lm(r̂_ij)

# 多体消息：把 j、k 两个邻居的边特征组合起来
m_i(jk) = m_ij ⊗ m_ik        # 张量积 → 直接含 i-j-k 三体信息
                              # 再配一层就够到四体

代价是单层计算更贵，但总层数从 3–4 层降到 2 层。而层数少意味着：误差不逐层累积、显存占用低、推理快。

积木三：读出能量

每个原子把周围信息汇总成一个标量（只取 l = 0 的那一阶，因为能量是旋转不变的标量），得到单原子能量 Ei。总能量就是求和：

E_total = Σ_i E_i

这个求和隐含一个假设：能量是局域的——一个原子的能量只取决于它周围 5–6 Å 内的环境。这条假设让计算量随原子数线性增长，而 DFT 是三次方。这才是"快"的根本原因，不是网络结构。

3.3 你加载的到底是哪个模型

模型训练数据什么时候用
MACE-MP-0
你正在用的		MPtrj（Materials Project 轨迹，约 150 万构型，89 元素）无机固体、氧化物、金属。你的 Bi₂WO₆ 属于这一类。模型分 small / medium / large，你现在用 medium。

3.4 五个局限（面试一定会问）

1. 它不知道电子结构
只给能量和力，不给带隙、不给电荷、不给能带位置。而光催化的核心恰恰是 band alignment（导带/价带位置决定能不能还原/氧化）。这是 MACE 在你课题上的硬边界——它能帮你算结构和吸附能，不能帮你算光吸收。
2. 分布外会静默失效
遇到训练集里没见过的构型，它不会报错，只会给你一个看起来合理的错数字。这是通用势函数最危险的地方，也是为什么"适用域研究"本身就是一个正经课题。
3. 元素覆盖不均
Materials Project 里 Bi 的化合物数量远少于 Si、Al、Fe。重元素 + 复杂氧化物 + 缺陷的组合，样本更稀。你的体系正好在稀疏区。
4. 没有长程静电
截断半径之外的信息全部丢失。对离子性强的氧化物（Bi₂WO₆ 就是），非局域电荷效应是有影响的。MACE-Polar 部分弥补，但你现在没用。
5. 自旋和氧化态不显式
CHGNet 那类"电荷感知"模型能预测磁矩，MACE-MP-0 不行。如果你的 Pd 单原子有自旋态变化，这一块它是盲的。

3.5 怎么判断它给你的数靠不靠谱（三条实操）

  1. 抽 5–10 个构型做 DFT 单点对比。不用全做，抽样即可。看能量差是否在你可接受的窗口内（比如 <20 meV/atom）。这是最硬的一条证据，面试时说出来分量很重。
  2. 算能量-体积曲线（EOS）。把晶胞压缩/膨胀几个点，看曲线形状是否合理、平衡体积是否接近实验。曲线歪了说明势函数在这个体系上不可信。
  3. 看力的连续性。把某个原子轻微挪动，力应该是连续变化的。出现跳变说明落到了训练分布外。
如果你只记住一句话：MACE 是一个插值器，不是求解器。它在训练数据覆盖的空间里非常准、非常快；一旦走出那个空间，它会安静地骗你。
所以真正的专业能力不是"会用 MACE"，而是"知道什么时候不该信它"。这句话，就是你面试时区别于其他候选人的地方。
