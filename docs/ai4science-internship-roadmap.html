02定位修正：零基础把 A 类岗关掉了

上一轮说的三个入口，现在必须做减法。原因是数学的，不是态度的。

入口典型岗位对你的门槛结论
A 类 · 模型算法岗 字节 Seed 物质发现算法、MSRA AI4S 研究实习、AISI 蛋白结构生成 要求：PyTorch 熟练 + 顶会/竞赛 + 独立复现论文。竞争者是 CS 博士。 2027 年前不要投。可以留作 2028 年的目标，但不能当第一站。
B 类 · 数据与评测岗 科学文档/谱图解析、数据集构建、benchmark 评测、科学多模态数据 要 pandas + 清洗 + 一点模型。化学背景是硬通货，因为要判断"这条数据对不对"。 首选。零基础 20 周可达，且你的化学判断力在这类岗位比代码更值钱。
C 类 · 干湿闭环 / 仪器 Agent AISI 科研仪器智能体、深势 Uni-Lab、晶泰自动化实验室、字节自动化系统 要"真做过实验 + 会写脚本调仪器 + 理解 Agent 工具调用"。CS 人补不了实验直觉。 并列首选，且是长期最优。你在这里的稀缺性最高。
一句话定位：你不是"要转行做算法的人"，你是"能把化学实验变成可编程、可回流数据的人"。这句话直接对应 C 类岗的 JD 原文——AISI 那个岗位写的就是"把实验流程与操作知识转化为智能体可用的结构化能力"。

这条路为什么对零基础友好：C 类岗的代码量远小于算法岗，但要求你懂仪器、懂实验误差、懂什么叫"这个数据不可信"。这三样你已经有，CS 人没有。

W10 在公开数据集（ESOL / Tox21 / Lipophilicity）上跑 GIN；读 Uni-Mol 论文的方法和实验部分 一条能复现的 baseline，指标写进 README 能对比"传统描述符 vs 图神经网络"在你数据上的差异

W12 写技术报告：问题、数据、方法、结果、失败分析。失败分析比结果更值钱 3000 字报告 + 仓库 + 一张 parity plot 报告里有一个"我试了但没成功"的段落

W14 补"大模型"三个字：Transformer 直觉、LoRA 微调、RAG 流程、Agent 工具调用 一个能跑的 RAG demo（读你的领域文献） 能说清"检索召回率怎么评、失败case长什么样"
W15–W16 投递 + 面试复盘。每场面试后当天写 300 字复盘 投递记录表（机构 / 岗位 / 状态 / 复盘） 至少投出 15 家，拿到 2 场面试
时间预算怎么挤（放羊导师的用法）
工作日每天 2 小时（晚上 21:00–23:00，实验跑着的时候正好）+ 周末每天 5 小时 = 每周 20 小时。20 周 ≈ 400 小时。
不要停实验去学代码——你还要毕业，而且实验数据正是项目一的原料。

04两个项目，不要多

零基础的人最常见的死法是"项目太多、每个都浅"。你只需要两个，但要做到别人能复现。

项目一 · 你的课题数据集（W2–W8）
把博士课题的实验记录整理成表格数据集，训练传统模型 + 神经网络预测性能指标，做交叉验证与特征重要性分析。

它证明的是：你有别人没有的数据和问题品味。
它不证明：你会训练大模型。

关键：数据量小不是问题，编数据才是。样本只有 80 条就老实写 80 条，并把"小样本下怎么做可靠评估"讲清楚——这反而是面试加分项。
项目二 · 复现一个开源模型（W9–W12）
在公开数据集上复现 Chemprop 或 Uni-Mol 的推理，指标对齐原文，写清差异原因。

它证明的是：你的代码能跑、能读论文、能定位问题——这是所有面试官对非科班的第一疑虑。

关键：不要挑最难的。挑一个"一周能跑通、两周能对齐"的。复现失败也可以在报告里写清楚，但要写出你排查了哪几步。

    07零基础特有的四个坑

    坑一：看视频代替写代码

    零基础的人 80% 的时间花在"看懂了"，但面试考的是"写得出"。硬规则：任何教程，看 30 分钟必须停下来自己敲一遍。一周结束时没有 commit，就算这周失败，下周补上。

    坑二：放羊导师 = 没人给你纠错

    这是"放羊"最被低估的代价。实验做错了，仪器会告诉你；代码写错了，只有人才能告诉你。必须主动找一个人：组里会用 Python 的师兄、隔壁计算组的同学、或一个固定的线上学习搭子。每周把你的代码给别人看一次，哪怕只是让他跑一遍你的 README。

    坑三：以为要"先学完数学"

    你不需要先补线性代数和概率论。顺序反了。先用起来，遇到不懂的公式再回去查——这样学的数学是"有用的数学"，而不是"考试用的数学"。真正需要提前补的只有一个：能看懂矩阵乘法在做什么。

    坑四：把实习当成逃离博士的出口

    直博三年级最危险的心态是"实验做不下去，所以去搞 AI"。面试官能闻出来。正确的叙事是："我的课题卡在试错成本太高，我想用机器学习把搜索空间压下来。"这个叙事既真实，又正好是 AI4Science 的存在理由。它同时解决了导师同意、面试说服、论文选题三个问题。

    08Plan B：如果 20 周后走不通

    诚实地说：零基础 20 周拿到 AI4Science 实习，概率不高，但不是零。所以需要一个不丢人的退路。

    退路不是失败，是换一个更宽的入口
    如果 2027 年 3 月投递没有回音，不要加码投算法岗，改为：

    ① 把项目一做成一篇文章（哪怕中文核心或会议），"机器学习辅助 XX 催化体系筛选"——这篇论文本身就是 AI4S 的入场券；
    ② 转向博士后的 AI4S 岗：AISI、上海 AI Lab、中科大科学智能中心这类机构的博士后普遍 16–25K，明确要博士、不要 CS 学历，且更看重领域理解；
    ③ 走"计算+实验"复合型路线：高校教职和研究所现在最缺的正是"既会做实验又会跑模型"的人，这比纯算法岗竞争小得多，而且你的博士没白读。

    三条退路都比"硬转纯算法岗"的现实。
